Key Features by Module
======================

📦 core.camera
  ✓ Camera intrinsic matrix computation
  ✓ Rotation matrix from pan/tilt/roll
  ✓ Camera calibration and projection
  ✓ 3D to 2D projection
  ✓ Visibility checking

📦 core.coordinate_system
  ✓ GPS to UTM coordinate conversion
  ✓ World coordinate system establishment
  ✓ Scene bounds computation
  ✓ Ground plane equation

📦 core.ground_plane
  ✓ Ground plane homography computation
  ✓ Image to ground coordinate mapping
  ✓ Ground footprint extraction
  ✓ Image warping to bird's-eye view

📦 vision.segmentation
  ✓ Semantic segmentation (SegFormer)
  ✓ Class mapping (ADE20K to site map classes)
  ✓ Confidence extraction
  ✓ Boundary detection from masks

📦 vision.feature_extraction
  ✓ Line detection (Hough transform)
  ✓ Vanishing point detection (RANSAC)
  ✓ Horizon detection
  ✓ Feature matching between views

📦 fusion.occupancy_grid
  ✓ Probabilistic occupancy representation
  ✓ World to grid coordinate conversion
  ✓ Bayesian cell updates
  ✓ Ray tracing
  ✓ Occupancy map extraction

📦 fusion.bayesian_fusion
  ✓ Multi-view observation fusion
  ✓ Confidence-weighted updates
  ✓ Distance-based weighting
  ✓ Viewing angle consideration

📦 fusion.wall_extraction
  ✓ RANSAC line fitting
  ✓ Collinear segment merging
  ✓ Wall confidence scoring
  ✓ Minimum length filtering

📦 rendering.renderer
  ✓ 2D site map visualization
  ✓ Occupancy grid rendering
  ✓ Wall segment rendering
  ✓ Camera position and FOV visualization
  ✓ Top-down view export

📦 utils.geometry
  ✓ Rotation matrix utilities
  ✓ Vector operations
  ✓ Line-line intersection
  ✓ Point-in-polygon test
  ✓ Plane fitting (RANSAC)


CLI Commands
============

Validate configuration:
    python src/cli.py validate --config config/example_site.yaml

Generate site map:
    python src/cli.py generate \
        --config config/example_site.yaml \
        --output output/sitemap.png \
        --dpi 150 \
        --export-data

Options:
    --no-occupancy    Hide occupancy grid
    --no-walls        Hide walls
    --no-cameras      Hide cameras
    --no-fov          Hide camera FOV


Python API
==========

from src.generator import GeometricSiteMapGenerator
from src.core.camera import CameraConfig, CameraOrientation, CameraIntrinsics

# Define cameras
cameras = [CameraConfig(...), ...]

# Create generator
generator = GeometricSiteMapGenerator(
    cameras=cameras,
    grid_resolution=0.05,
    segmentation_model="nvidia/segformer-b5-finetuned-ade-640-640"
)

# Generate
occupancy_grid, walls = generator.generate(
    min_wall_length=0.5,
    confidence_threshold=0.5
)

# Render
generator.render(output_path, dpi=150)

# Get statistics
stats = generator.get_statistics()

# Export data
generator.export_data(output_dir)

Development Workflow

1. Setup:
    python -m venv venv
    source venv/bin/activate
    pip install -r requirements.txt
    pip install -e .

2. Make changes to src/

3. Run tests:
    pytest tests/

4. Validate configuration:
    python src/cli.py validate --config config/my_site.yaml

5. Generate site map:
    python src/cli.py generate --config config/my_site.yaml --output output/test.png


Performance Benchmarks
======================

Typical 4-camera site (1920×1080 images):

Phase 1 (Coordinate system): < 0.1s
Phase 2 (Camera calibration): < 0.5s
Phase 3 (Load segmentation model): ~5-10s (first time, cached after)
Phase 4 (Semantic segmentation): ~2-5s per image (GPU), ~30-60s (CPU)
Phase 5 (Occupancy grid creation): < 0.1s
Phase 6 (Multi-view fusion): ~5-10s
Phase 7 (Wall extraction): ~1-2s
Phase 8 (Rendering): ~2-3s

Total: ~30-60s (GPU) or ~2-5 minutes (CPU)

Memory usage: ~1-2GB peak (including model)
