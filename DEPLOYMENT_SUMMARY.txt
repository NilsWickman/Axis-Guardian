1. VPS Setup (One-Time)

   ──────────────────────

================================================================================
  TROUBLESHOOTING QUICK FIXES
================================================================================

Services won't start:
  → Check logs: sudo journalctl -u SERVICE_NAME -n 50

SSL failed:
  → Verify DNS: dig +short your-domain.com
  → Ensure port 80 open: sudo ufw allow 80/tcp

Login not working:
  → Check auth service: sudo systemctl status auth-service
  → Verify DB: sudo -u postgres psql surveillance

Cameras not loading:
  → Check MediaMTX: sudo systemctl status mediamtx
  → Check streams: sudo systemctl status camera-streams
  → Verify VPS_PUBLIC_IP in .env.production

Firewall blocking:
  → Review rules: sudo ufw status verbose
  → Check blocked IPs: sudo axis-guardian-firewall blocked
